# Civic Analytics Portfolio

This repository contains my professional portfolio showcasing civic analytics projects and experience highlighting my academic background and technical skills related to civic analytics.

## Structure

**Home** (index.qmd): Introduces my academic background and professional interests, with a profile photograph and links to my email, GitHub, LinkedIn, and downloadable resume.

**Past Project Showcase** (projects.qmd): Highlights my research examining CTA transit stop distribution and racial composition across Chicago communities. The page includes the project's objectives, methods, key findings, and a downloadable PDF presentation.

## Design Choices

I selected the Cosmo theme because it provides a clean, professional layout while maintaining a modern appearance. I customized the website using a forest green and light gray color palette to create a cohesive design and used rem to support consistent text across different screen sizes. The homepage uses Quarto's jolla About template to organize my biography, profile photograph, and professional links.

## Advanced Quarto Feature

The Past Project Showcase includes a Quarto callout to provide additional context about my attatched project.
